# Leaf Disease Detection - Project Plan

## Objective
Build a deep learning model to detect diseases from plant leaf images.

---

## Week 1
- Create GitHub repository
- Collect dataset
- Organize folders
- Install dependencies

## Week 2
- Image preprocessing
- Resize and normalize images
- Split training and testing data

## Week 3
- Build CNN model
- Train model
- Improve accuracy

## Week 4
- Test model
- Save trained model
- Prepare documentation

---

## Tools Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Jupyter Notebook

---

## Expected Output
A model that predicts whether a plant leaf is healthy or diseased.
