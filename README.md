# Code-alpha-leaf_disease_detection
Deep learning based plant leaf disease detection using CNN and image processing.

# Leaf Disease Detection using Deep Learning

## Objective
Detect and classify diseases in plant leaves using image processing and CNN models.

## Features
- Leaf image preprocessing
- Disease classification
- Healthy vs infected prediction
- CNN based training
- Model evaluation

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
PlantVillage Dataset

## Folder Structure
src/ - source code  
notebooks/ - experiments  
models/ - trained models  
results/ - outputs  
docs/ - documentation

Project initialized. Dataset collection and preprocessing phase started.
